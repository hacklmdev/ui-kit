## Design principles

1. **Monospace-first** — JetBrains Mono for all data, counts, labels, status text.
2. **Minimal radius** — `4px` only. No large rounded corners.
3. **Token-driven dark mode** — flip `.dark` class on any ancestor. Semantic tokens handle the rest.
4. **Accent** — `#fb631b` (HackLM orange). Use _rarely_ — primary CTAs and active states only.
5. **No shadows except modals** — borders define elevation.

## Fonts

```
Inter         → body, headings, prose
JetBrains Mono → labels, counts, IDs, code, buttons
```

Both loaded from Google Fonts in `global.css`.
