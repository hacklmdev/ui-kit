## Tailwind usage

Every token is usable as a Tailwind class:

```html
<!-- Brand -->
<div class="bg-accent text-white">Primary</div>
<div class="hover:bg-accent-hover">Hover</div>

<!-- Borders -->
<div class="border border-grid">Card</div>

<!-- Text -->
<p class="text-muted">Secondary text</p>
<span class="text-faint">Metadata</span>

<!-- Background -->
<body class="bg-background">…</body>
```
